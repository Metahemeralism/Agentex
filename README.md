# AgenTeX

**From research code to a submitted paper: agent skills for LaTeX.**

Equations from your code · publication-grade TikZ · verified citations · code-vs-paper audits · prior-work search · overlap screening · mock peer review · one-command arXiv packages

AgenTeX is a set of [Agent Skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) that make an AI coding agent a careful co-author. It reads your repository, writes the LaTeX that describes it, checks that the paper still matches the code, finds the work reviewers will compare you to, and packages the result for arXiv.

It's for researchers, PhD students, and undergraduates writing a thesis: anyone whose results live in code and whose write-up lives in LaTeX.

## Skills

| | Skill | What it does |
|---|---|---|
| **Write** | [`latex-project`](skills/latex-project/SKILL.md) | Scaffolds a paper/thesis next to your code (templates, packages, `latexmk`, Overleaf); `texmap.py` gives agents a compact project map |
| | [`latex-math`](skills/latex-math/SKILL.md) | Code → equations via a symbol map, checks shapes and indices against the implementation, keeps notation consistent |
| | [`latex-tikz`](skills/latex-tikz/SKILL.md) | 12 tested diagram patterns, a shared style sheet, offline search of **1,229 official TikZ manual examples**, compile-and-preview script |
| | [`latex-algorithms`](skills/latex-algorithms/SKILL.md) | Functions → `algorithmicx` pseudocode, or `minted`/`listings` blocks pulled straight from source files |
| | [`latex-tables-figures`](skills/latex-tables-figures/SKILL.md) | Results → `booktabs`/`siunitx` tables and vector plots, generated by code so numbers never drift |
| | [`latex-beamer`](skills/latex-beamer/SKILL.md) | Paper → timed talk with claim-style titles, reused figures and notation, speaker notes |
| **Check** | [`latex-references`](skills/latex-references/SKILL.md) | Citations from DOIs/arXiv, never invented; `check_refs.py` finds undefined, duplicate and unused labels and citations |
| | [`latex-consistency`](skills/latex-consistency/SKILL.md) | Audits paper ↔ code: equations vs implementation, hyperparameters vs configs, tables vs result files, overclaims, leakage |
| | [`latex-research-check`](skills/latex-research-check/SKILL.md) | Finds the closest prior work (OpenAlex + arXiv + Semantic Scholar), ranked by similarity to *your* abstract, with a novelty-risk verdict |
| | [`latex-plagiarism-check`](skills/latex-plagiarism-check/SKILL.md) | Screens for verbatim and near-verbatim overlap with sources, and flags uncited or unquoted reuse |
| | [`latex-review`](skills/latex-review/SKILL.md) | Conference-reviewer mode: venue-style scored review, 3-reviewer panel + meta-review, line-level writing review, anonymity checklist, rebuttal prep |
| **Ship** | [`latex-arxiv`](skills/latex-arxiv/SKILL.md) | Packages only the files the document uses, strips comments, catches arXiv failures, test-compiles the package |
| | [`latex-debug`](skills/latex-debug/SKILL.md) | `texlog.py` turns a thousand-line log into the few lines that matter; lookup table of common errors |

## Install

**Claude Code (plugin)**

```text
/plugin marketplace add Metahemeralism/AgenTeX
/plugin install agentex@agentex
```

**Claude Code (manual)**

```bash
git clone https://github.com/Metahemeralism/AgenTeX.git
cp -r AgenTeX/skills/* ~/.claude/skills/              # all projects
cp -r AgenTeX/skills/* your-project/.claude/skills/   # or one project
```

**Claude apps (claude.ai / desktop):** zip a skill folder (e.g. `skills/latex-tikz/`) and upload it under *Settings → Capabilities → Skills*.

**Other agents:** each skill is a folder with a `SKILL.md` in the open Agent Skills format. Agents that don't support skills can be pointed at the `SKILL.md` as instructions.

**Requirements:** Python 3.8+ (all scripts are standard library only). Compiling needs TeX Live / MacTeX, or the lightweight [`tectonic`](https://tectonic-typesetting.github.io) (`brew install tectonic`). Optional: `pdftoppm`/`pdftotext` from poppler, for figure previews and PDF sources.

## Use it

Just ask; the matching skill loads itself.

```text
> Draw the model in src/model.py as a TikZ figure with tensor shapes.
> Write the loss in train.py as an equation and add new symbols to macros.tex.
> Turn the training loop into an algorithm box.
> Make a booktabs table from results/seeds.csv (mean ± std per method).
> Does my paper match my code? Check hyperparameters, equations and Table 2.
> Has anyone done this before? Find the closest work to my abstract.
> Check the intro and related work for overlap with the papers I cite.
> Review my paper as a NeurIPS reviewer. Then do a 3-reviewer panel.
> Package paper/ for arXiv.
> It won't compile. Here's the log.
```

Or call one directly, e.g. `/agentex:latex-review` (plugin) or `/latex-review` (manual install).

### Scripts you can also run yourself

| Script | Does |
|---|---|
| `latex-project/scripts/texmap.py paper/` | Project map: input tree, outline with `file:line`, labels, macros, bib usage, missing figures, TODOs |
| `latex-tikz/scripts/tikzref.py brace decoration` | Top official TikZ examples for a query (offline) |
| `latex-tikz/scripts/tikzcheck.sh fig.tex` | Compile a figure; print errors only plus a small PNG preview |
| `latex-references/scripts/check_refs.py paper/` | Undefined/duplicate labels, missing/uncited bib entries (CI-friendly exit code) |
| `latex-debug/scripts/texlog.py main.log` | Log digest: first errors with context, warnings grouped |
| `latex-research-check/scripts/related.py --from-tex main.tex` | Closest prior work, deduplicated across three databases |
| `latex-plagiarism-check/scripts/overlap.py paper/ sources/` | Sentence-level overlap with cited/quoted status |
| `latex-arxiv/scripts/arxiv_pack.py main.tex --compile` | arXiv-ready folder + `.tar.gz`, test-compiled |

## Built to be token-efficient

Agent work on LaTeX burns context fast: whole-paper reads, 2,000-line logs, regenerated figures, fetched manual pages. AgenTeX borrows proven techniques from the [ponytail](https://github.com/DietrichGebert/ponytail) and [agent-skills](https://github.com/addyosmani/agent-skills) plugins:

| Technique | In AgenTeX | Effect (measured on this repo) |
|---|---|---|
| Lean, always-loaded descriptions | 13 descriptions, ~250 characters each | ~3.3 KB total in every session; bodies load only on use |
| Small skill bodies, references on demand | `SKILL.md` 2.8–5.5 KB; review forms in a separate file | One skill's worth of context per task |
| Compact project map (ponytail's codebase map) | `texmap.py` | Template project mapped in 663 characters |
| Deterministic scripts beat reading | `texlog.py`, `check_refs.py`, `arxiv_pack.py` | A 1,150-line compile log → **1 line** |
| Local reference cache (agent-skills' doc cache) | `tikzref.py` over 1,229 extracted examples | 248 characters returned vs a **624 KB** manual page |
| Write styles once | `agentex-tikz.sty` | Figures average ~22 lines, with no per-figure style preamble |
| Copy and edit, don't regenerate | Patterns and templates via `cp` + targeted edits | Output tokens spent only on what differs |
| Cheap visual checks | 100 dpi PNG previews instead of PDFs | A few hundred image tokens per look |
| Files, not chat | Reviews and reports written to `review/` | Replies stay a few lines |

## Design principles

- **The code is the source of truth for facts; the author decides intent.** When paper and code disagree, AgenTeX shows both and asks.
- **Never fabricate.** Citations, related work and reviews cite real, resolvable sources, or say `TODO-verify`.
- **Generate, don't transcribe.** Numbers, tables and plots are written by scripts, so they can't drift.
- **One notation system.** A single `macros.tex` shared by paper, figures and slides.
- **Compile-first.** Every template and pattern here compiles. Every figure is looked at before it's handed over.

## Honest limits

- `latex-plagiarism-check` finds verbatim and near-verbatim overlap with sources it can read. It is **not** iThenticate/Turnitin (no paywalled databases), and AgenTeX deliberately offers no "AI-text detection" because those detectors are unreliable.
- `latex-research-check` searches open databases; coverage and recency are good but not complete. It reports novelty *risk*, never a guarantee.
- arXiv doesn't run biber: biblatex users must ship a `.bbl` built with a biblatex version that matches arXiv's TeX Live. `arxiv_pack.py` warns about this.
- Review score scales change yearly; `latex-review` uses the current venue form when you provide it.

## Contributing

Issues and PRs are welcome, especially new diagram patterns, venue review forms, and error→fix pairs for `latex-debug`.

- One skill = one folder with a `SKILL.md`. The `description` decides when the skill triggers: say *when to use it*, in under ~300 characters.
- Keep `SKILL.md` scannable; put long reference material in separate files the skill links to.
- Scripts: standard library only, each with a small test. Run all tests with:
  ```bash
  for d in skills/*/scripts; do python3 -m unittest discover -s "$d" -q || exit 1; done
  ```
- New TikZ patterns must compile standalone with `agentex-tikz.sty` and use its shared styles.

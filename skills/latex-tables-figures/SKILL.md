# Results → Tables & Figures

Core principle: **generate, don't transcribe.** Numbers typed by hand into a paper drift from the code. Have a script write `.tex`/`.pdf` files into `paper/tables/` and `paper/figures/`, and `\input` them. Report the generated file's path in chat; don't paste the table back. For the full pipeline (results registry, stale-number audit, figure provenance), use `latex-results-sync`.

## Tables

### Generate from code

pandas (≥ 1.3, uses `Styler`):

```python
# Writes a booktabs table body; the caption/label stay in the .tex file.
(df.style
   .format(precision=2)
   .hide(axis="index")
   .to_latex("paper/tables/results.tex", hrules=True,   # \toprule/\midrule/\bottomrule
             column_format="lSS"))
```

R: `knitr::kable(df, "latex", booktabs = TRUE)` or `xtable`. Julia: `PrettyTables` with `backend = Val(:latex)`.

For mean ± std over seeds, format strings in code (`f"{m:.1f}({s*10:.0f})"` for siunitx uncertainty, or `f"{m:.1f} $\\pm$ {s:.1f}"`).

### Typeset

```latex
\begin{table}[t]
  \centering
  \caption{Captions go \emph{above} tables.}\label{tab:results}
  \begin{tabular}{@{}l S[table-format=2.1] S[table-format=1.3]@{}}
    \toprule
    Method & {Acc. (\%) $\uparrow$} & {Loss $\downarrow$} \\
    \midrule
    Baseline & 88.1 & 0.412 \\
    Ours     & 91.3 & 0.287 \\
    \bottomrule
  \end{tabular}
\end{table}
```

Rules:
- `booktabs`: no vertical rules, no double rules; `\cmidrule(lr){2-3}` for grouped headers.
- `siunitx` `S` columns align on the decimal point; wrap text headers in `{}`.
- Consistent precision per column, justified by the noise (don't report 4 decimals when seeds vary in the 1st).
- Show direction (↑/↓) and units in headers; state what ± means (std, SE, 95% CI) and over how many runs.
- Bold the best *only* if the difference is meaningful; say how significance was assessed.
- Too wide → reduce columns, `\small`, `tabular*`/`tabularx`, or `table*` in two-column layouts. Avoid `\resizebox` (it produces inconsistent font sizes).

## Figures

### From matplotlib

Vector output, sized to the column so fonts match the text:

```python
import matplotlib.pyplot as plt
plt.rcParams.update({
    "font.family": "serif",
    "font.size": 9,            # match document \small/\footnotesize
    "text.usetex": False,      # True only if LaTeX is installed on the plotting machine
    "pgf.rcfonts": False,
})
fig, ax = plt.subplots(figsize=(3.4, 2.4))   # inches; ~\columnwidth in two-column
...
fig.savefig("paper/figures/loss.pdf", bbox_inches="tight")   # or .pgf for true document fonts
```

- `\textwidth`/`\columnwidth` in inches: run `\the\columnwidth` in the doc (pt) ÷ 72.27.
- `.pgf` output inherits the document font exactly (`\input{figures/loss.pgf}`), but compiles slower; `.pdf` is the pragmatic default.
- Never PNG/JPG for line plots; raster only for photos/heatmaps with very many cells.
- Colour-blind-safe palettes (e.g. Okabe–Ito, `tab10` with line styles/markers); never colour as the sole cue.
- Label axes with quantity *and unit*; legend shouldn't cover data.

### pgfplots (native LaTeX plots)

```latex
\begin{tikzpicture}
  \begin{axis}[width=\columnwidth, height=5cm, xlabel={Epoch}, ylabel={Loss},
               legend pos=north east, grid=major]
    \addplot+[mark=none] table[x=epoch, y=train, col sep=comma]{data/loss.csv};
    \addplot+[mark=none, dashed] table[x=epoch, y=val, col sep=comma]{data/loss.csv};
    \legend{Train, Validation}
  \end{axis}
\end{tikzpicture}
```

Reads the CSV your code writes, so the figure stays in sync.

### Placement and subfigures

```latex
\begin{figure}[t]
  \centering
  \begin{subfigure}{0.48\linewidth}
    \includegraphics[width=\linewidth]{figures/a.pdf}
    \caption{Training loss.}\label{fig:loss:a}
  \end{subfigure}\hfill
  \begin{subfigure}{0.48\linewidth}
    \includegraphics[width=\linewidth]{figures/b.pdf}
    \caption{Validation accuracy.}\label{fig:loss:b}
  \end{subfigure}
  \caption{Captions go \emph{below} figures.}\label{fig:loss}
\end{figure}
```

- `[t]` or `[tbp]` placement; avoid `[h!]`/`[H]` fights. Floats far from their reference → move the float earlier in source, not `[H]`.
- `\label` **after** `\caption`, or references point to the section.
- Every figure/table is referenced in the text, and the caption is self-contained (what, how measured, key takeaway).
